Pankaj Kumar Rajpoot — Singer & Musician Website

Files:
- index.html: website content
- style.css: responsive design
- script.js: booking form -> WhatsApp message
- assets/pankaj-stage-photo.png: supplied stage photo (included when available)

Publish on GitHub Pages:
1. Create a public repository on GitHub, e.g. pankaj-singer-website.
2. Upload all files/folders in this ZIP (not the ZIP itself); index.html must be at the repository root.
3. In repository Settings -> Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for publishing and open the Pages URL shown there.

Notes:
- Call and WhatsApp buttons use +91 70074 18571.
- The booking form prepares the enquiry in WhatsApp; the visitor must press Send in WhatsApp.
- YouTube, Instagram and Facebook links are based on the profiles supplied in chat.
- Update contact/social links in index.html if they change.
